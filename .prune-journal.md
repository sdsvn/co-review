# Prune journal

## 2026-09-25 - One home for CO_REVIEW_HOME

**Learning:**
`$CO_REVIEW_HOME || ~/.co-review` was computed separately in `ReviewStore`, `BundleService` and `CoReviewerMcp`
(store, inline review directories, server registry). They must agree, so the rule now lives in `coReviewHome()`
(`extensions/review/src/node/review-store.ts`). `bin/server.mjs` has its own copy on purpose: the CLI is plain ESM
that runs without the compiled extension, so it cannot import it. Keep the two in sync rather than coupling them.

**Action:**
Look for other config rules duplicated across backend services before adding a new one.
